# Guía de Desarrollo

Esta es otra subcarpeta anidada dentro de `guias/desarrollo`.

## Entorno Local

Para configurar tu entorno de desarrollo, sigue estos pasos:

=== "Windows"
    ```bash
    git clone https://github.com/proyecto-web-abaq/backend.git
    cd backend
    npm install
    npm run dev
    ```

=== "macOS / Linux"
    ```bash
    git clone https://github.com/proyecto-web-abaq/backend.git
    cd backend
    npm install
    npm run dev
    ```
