# Guía de Usuario

Esta es una subcarpeta anidada dentro de `guias/usuario`.

## Ejemplo de bloques con pestañas

Para usar la plataforma ABAQ, dependiendo de tu rol:

=== "Estudiante"
    1. Inicia sesión con tu matrícula.
    2. Sube tus documentos de servicio social en PDF.
    3. Registra tus horas semanales.

=== "Coordinador"
    1. Revisa la bandeja de documentos pendientes.
    2. Aprueba o rechaza los reportes de horas.
    3. Genera constancias de liberación.

=== "Administrador"
    1. Gestiona las cuentas de coordinadores.
    2. Configura los catálogos del sistema.
